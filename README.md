# Glam Auto-Post Studio 🦋

A Glam Hustle Hub tool. Create social media content in your own voice, schedule it once for every platform, and keep a **proof log** — a post only counts as posted once its live link is saved.

## What's inside

- **Queue** — what's up next, a plain-English status line, drafts, and past-its-time flags
- **Create** — type a plain idea, tap *Write it in my voice*, pick your platforms, schedule it or save a draft
- **Posted** — your proof log with live links, plus a *Needs attention* list for anything that didn't post
- **Accounts** — your handles for Facebook, Instagram, TikTok, YouTube, Threads, Pinterest, X, and LinkedIn, with a connection check. Live auto-posting switches on per platform once that platform approves the app; everything else works now
- **My Voice** — your tone, signature phrases, sample caption, emoji and hashtag style, and call to action, so the writing sounds like you

All user data is stored in the browser on the user's own device (localStorage). Nothing is uploaded, and we never sell data.
